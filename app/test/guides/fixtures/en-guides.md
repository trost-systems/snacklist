# Guides

Step-by-step guides for the parts of Snacklist that aren't explained inside the app. Some guides are only available in German for now; each page says so up front.

-   [Connect Snacklist to Claude](https://snacklist.app/en/guides/claude)

    Connect Claude to your Snacklist in under five minutes. Then Claude adds items, ticks them off and tells you what's still missing.

-   [Snacklist with Alexa: set up the skill](https://snacklist.app/en/guides/alexa)

    With the Snacklist skill for Alexa you can add things to your Snacklist by voice: "Alexa, ask Snacklist to add milk and eggs". Here's how to set it up in a few minutes.

-   [Snacklist with Siri (German only for now)](https://snacklist.app/en/guides/siri-shortcut)

    The Snacklist Siri Shortcut works in German only for now. Here's what that means and where to find the German setup guide.

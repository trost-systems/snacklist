# Household controls: where they were and where they are now

Flag `list-declutter` (PostHog 362082) on. With it off, nothing moves.

| Control | Was (More) | Now (switcher sheet, list tab) |
| --- | --- | --- |
| Household row (name) opening the household page | More, household group | Removed from More; the sheet's household page is the page |
| „Partner einladen“ row | More, household group | Removed; „Einladen“ button and members page „Leute einladen“ (already there), invite hints open the invite page |
| Rename household | Household page | **Moved**: pencil next to the name |
| Members list, roles, make admin, remove (confirm) | Household page | Members page (already there) |
| Leute einladen, open invites, revoke, group link | Household page / Einladungen | Invite page and members page (already there) |
| Lists (rename, delete, order, new) | Household page | Household page of the sheet (already there) |
| Currency („Währung“, prices flag) | Household page | **Moved**: household page |
| Confirm new members switch and join requests (owner/admins) | Household page | **Moved**: household page |
| Default household for Siri, Alexa, KI and default list | Household page | Households page „Siri, Alexa & KI“ (already there) |
| Leave household (leave, archive, delete, billing confirm) | Household page | **Moved**: household page, bottom; closes the sheet after leaving |
| Archived households | More, household group | Stays in More (own group) |
| Join with code | Not in this section | Unchanged |

## What was built

- `app/lib/core/screen_reader.dart`: `ScreenReader.of(context)` with `announce`, `moveFocus` (by
  `Semantics.identifier`), `identifiers`, `neighbourOf`. It speaks after the frame that shows the
  change, 300 ms later while VoiceOver or TalkBack runs, and joins one moment's announcements. Lint
  `announce-through-screen-reader` (ast-grep) keeps every announcement on it; the 7 existing call
  sites moved.
1. Add: „<Name> hinzugefügt“ / "<Name> added" (`AddSheet`, compact too).
2. EN "Qty" → "Quantity".
3. Add sheet container unnamed (identifier `add-sheet`).
4. Tick: said as the row leaves; focus to the next row (`item-<id>` identifiers).
5. Store done card: said and focused as it appears.
6. Put back: „<Name> wieder auf der Liste“; focus on the top row of „Zuletzt verwendet“ (`used-<id>`),
   else the row put back, else the list's last row.
7. Edit: `editSaid` in `edit_item_sheet.dart`, every saved field; emptied fields „… entfernt“;
   nothing without a change.
8. `QuantitySemantics`: one adjustable node in the add sheet, the edit sheet (both layouts) and the
   price editor's count; steppers excluded. iOS and Android only: the web keeps the labelled
   buttons (its adjustable node is a range input a click also moves; DECISIONS Job 474).
9. „Beitritte bestätigen“ explainer as the switch's subtitle.
10. Household-level open count removed (switcher page, household rows); `Household.openCount` and
    the `openNow` plumbing deleted.
11. `_ListArrival` in `shell.dart`: „Auf Liste … im Haushalt …, n offen“ with plurals.
12. More: no app bar (phone and wide), a heading node „Mehr“ / "More" above the rows.

Docs: `docs/ACCESSIBILITY.md` (new), `docs/DECISIONS.md` (Job 474), `docs/NEEDS_PETER.md` (Job 474,
device check), feature files and FEATURES-FOR-WRITERS sections.

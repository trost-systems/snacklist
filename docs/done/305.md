## The rules

Core (`core`, `design`, `l10n`, `analytics`, `session`) imports only core. A feature imports core
and itself. The shell (`shell`, `more`, `main.dart`) imports anything, and nothing else imports
the shell. Each error names the fix. The 200 imports that broke a rule when the check came in are
in the baseline. A line that no longer occurs fails, and no pair of folders may hold more lines
than main has. After this job the baseline has 176 lines: analytics lost 8, and the list cycles
lost 16. The biggest pairs left are household→list (23), trip→list (16), onboarding→household
(14) and household→shell (11, route constants from `shell/router.dart`).

## R11 and R12: recommendation, with measured cost

A scratch prototype did R11 for real: `app/` became the pub-workspace root, with
`packages/design` (`snacklist_design`) and `widgetbook` as members, using a rerunnable codemod.
The measurements:

- **Size.** 140 files and +345/-309 lines, lockfiles left out. Widgetbook's `pubspec.lock` goes
  away, and `app/pubspec.lock` gains 64 lines.
- **Time.** pub get, analyze and the whole `flutter test` (118 to 130 s after vs 121 to 130 s
  before, warm, alternating runs on a shared host) are the same within noise. The package's own
  tests take 3.5 s warm, but only 2 of the 19 design test files can move, because the rest need
  `core/theme.dart` or feature widgets. The CI saving is about 0, which matches section 3 of the
  report.
- **l10n and assets were easy.** Design uses one string (`appTitle` in `BrandBlock`), which now
  comes in as a parameter. The fonts and images stay declared by the app. The goldens are
  byte-identical.
- **Two traps fail silently.** First, the app's `analysis_options.yaml` excludes `widgetbook/**`,
  and in a workspace that exclude hides Widgetbook's 11 real errors. Second, 10 ast-grep rules
  scoped to `app/lib/**` stop seeing the package. Also, a Widgetbook dependency bump would change
  `app/pubspec.lock`, which `ci-changes.sh` treats as native: each bump would start the 70-minute
  ios run.
- **Estimate.** About 4 to 5 h for a real PR.

**R11: not now.** The import-direction check already enforces "design imports no app code", and
the package saves no CI time. Do it when design gets a second consumer outside `app/`, using the
codemod and the two trap fixes above.

**R12: neither for now.** `oauth`'s screen needs l10n, the session and `shell/router.dart`'s
paths. Any feature package with screens first needs l10n as its own package, and about 88 files
import it. `review` is the only candidate. It takes two bools from `Environment`, one `track`
call, `Popups` and `ListCubit` (in the trigger), and `core/device_cache.dart` imports its
counters. Estimate: 5 to 7 h, with no CI gain. The cheaper next structural wins are inside the
current folders:

- Move route path constants from `shell/router.dart` into core (about 25 feature→shell lines).
- Untangle `core/device_cache.dart` from 7 feature folders (core→feature lines).
- Decide whether `purchases`, which imports only core, becomes core (23 lines). That is a call
  about Premium's place.

## What was built

- **Table and RPC.** `public.shopping_day_reminders` (migration `20261123000000_shopping_day_reminder.sql`):
  per person, off by default (no row), weekdays (ISO), the device's IANA time zone, language, `last_sent_on`.
  RLS: own row readable; writes only through `set_shopping_day_reminder`. Export key
  `shopping_day_reminder`, cascade on account deletion.
- **Cron.** `shopping-day-reminder` every 10 minutes (only while the server switch
  `push_shopping_day` is on, `shopping_day_set(true, url)`); `shopping_day_due` finds who is at
  19:00 to 19:29 local the evening before a picked weekday and not yet sent that local date;
  `shopping_day_run` marks sent first and posts to the `push` function through pg_net with the vault
  secret `push_send_secret`. The message is job 376's (`kind: list`), so a tap opens the list.
- **Open-item count: included.** One indexed count of the default list's open items; no names.
- **App.** `app/lib/settings/shopping_day.dart`: weekday chips in Einstellungen (flag
  `push-shopping-day`, push in the build), first pick asks for OS permission, time zone from
  `flutter_timezone`. Three new ARB strings.
- **Review 0 fixes.** Chips keep button and selected semantics (test); chips follow push state; the
  last weekday unpicked runs `PushRegistration.forget()` (N-401, test); the export has `last_sent_on`;
  zone and language refresh when the section opens; `last_sent_on` never moves back; more pgTAP.
- Flag `push-shopping-day` in `releases/flags.json`, `rollout: off`.

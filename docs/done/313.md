# Job 313: open the store's app (DL1) and linking stores to chains (SS)

Built from Peter's picks of 2026-11-19 on job 314's prototypes (OS1 + OS3, SS1 + SS2 with SS5's rules). Everything new
is behind the PostHog flag `open-store-app` (off, `releases/flags.json`); only the store header's restyle reaches
everyone. Decisions: `docs/DECISIONS.md`, "Job 313". Feature map: `.cursor/skills/verify-snacklist/features/store-apps.md`.

**What users get (flag on).**
- A store matched to a chain („zugeordnet“) with an app has an „<App> öffnen“ key at the end of its list header (OS1). A tap opens the
  app: Android starts the package (else Play), iPhone opens the chain's universal link if an app claims it (else the
  App Store page), the web app opens the app's store page; nothing goes to the chain. A one-time line under the first such header says what it does.
- The store's screen has an „App“ card with „Öffnen“ (OS3), a choice where the chain has two apps (stored per store),
  and the chain line („Zugeordnet: Lidl · Deutschland“, „Ändern“, „Zuordnung aufheben“, or „Kette zuordnen“ with a picker).
- Making a store (stores page, add sheet, edit sheet): chains offered while typing; a plain name that is a chain's asks
  „Ist das Lidl (Deutschland)?“ once; „Aldi“ asks which. Older stores are asked once from a card on the list, only
  where the chain has an app. The phone's region ranks the chains; other countries are found too („Hofer“).
- No store-name note anywhere in the app (Legal N-292); Legal's words „zugeordnet“ / "matched" (N-293).

**Everyone.** The store header looks like „Zuletzt verwendet“'s (Peter's pick 2): the name as plain text, the brand
rule, the count and a plain caret; the hex badge and the raised fold key are gone. From 200 % text the count is a
number only. The guided start's and „Neuer Haushalt“'s store steps lost the
store-name note (N-292).

**Legal texts (word for word, lead updates of 2026-11-19 21:10 to 21:16).** Imprint „Ladennamen“ / "Shop names" with
anchors (N-294), privacy §5 on the chain fields (N-296), §9 on „Laden-App geöffnet“ / "Store app opened" (N-304),
dates 19 November 2026. Merge waits for the lead's `LEGAL_GO_313`.

**Server.** Migration `20261119200125_retailers.sql`: `public.retailers` (59 chain × country entries, 68 apps, 8
countries; signed-in read only), `stores.retailer_chain/_country/_app/_answered` with a foreign key, and the RPCs
`match_retailers`, `answer_store_retailer`, `retailer_questions`. Source of the data: `supabase/retailers/retailers.json`;
`scripts/retailers.ts` writes the data migration (`--migration`), checks file, migration and the app's analytics
allow-list in the lint gate (`--check`), and re-verifies every store id and link online (`--verify`, 68 of 68 on
2026-11-19).

**Analytics.** `store_app_opened` {chain, country, outcome}, never the store's name (`docs/ANALYTICS.md`).

# Job 376: P0 push foundation (FCM, APNs via FCM, tokens, send function, deep link)

Status: PR open, not merged (stops for Legal + Ops, brief "Out"). Contract: `docs/PUSH.md`.

## What was built

- **Devices.** `public.push_tokens` (migration `20261122183000_push_tokens.sql`): one row per FCM
  token, owned by the user, RLS (own rows readable, no direct writes), `register_push_token` /
  `unregister_push_token`, 10 devices per user, purge after 270 days (`purge-push-tokens` cron),
  cascade on account deletion, `export_my_data().push_devices` without the token. pgTAP
  `supabase/tests/push_tokens.test.sql`, the outsider sweep and the backup drill fixture.
- **Send path.** Edge function `push` (`supabase/functions/push/`): `x-push-secret`, recipients
  with their own title and body, only members of the household and only a list of it, FCM HTTP v1
  with a service-account JWT (`jose`), 24 h expiry, unregistered tokens deleted, dry run. Answers
  and logs carry counts and fixed codes only. 503 until Ops sets the secrets.
- **App.** `app/lib/push/` (Firebase from the six `FIREBASE_*` defines, `PushRegistration`: opt-in
  is the only prompt, re-register on start and refresh, forget on sign-out), `shell/push_taps.dart`
  (a tap opens the named list, switching household first; cold start waits for the session),
  `ShowListLink` in the list view. Native: `aps-environment`, `POST_NOTIFICATIONS`. Release builds
  pass the defines from `vars.` (`release.yml`, Fastfile `PUSH_DEFINES`). Lint rule
  `firebase-only-in-firebase-push`.
- **Privacy drafts** (DE/EN §5 "Mitteilungen auf dem Smartphone", §8, §12, §13, §14) behind the new
  hold `push-notifications` (unreleased), `docs/PRIVACY_DATA_MAP.md`. No ARB copy: no UI yet.

# Job 282 (FX1): input mis-matching in the classifier

## What was wrong

Four words landed in another word's aisle, and one in the wrong aisle by our own data:

| Typed | Was | Now |
| --- | --- | --- |
| beer | produce (Beere) | drinks (synonym of Bier) |
| rolls | household (Rolle) | bakery (synonym of Brötchen) |
| sage | tools (Säge) | produce (synonym of Salbei) |
| Schäufele | garden (Schaufel) | meat (dictionary term) |
| Rohrnudeln | pantry (through „nudel“) | bakery (dictionary term) |

The brief named „Brötchen“ for the second row; „Brötchen“ itself was already bakery. The input
job 279 found was "rolls" (catalog/REVIEW.md on #510), which now files as Brötchen.

## Root cause

`public.item_key` stems German endings and folds umlauts before any lookup: beer and Beere both
give "beer", sage and Säge "sag", rolls and Rolle "roll", Schäufele and Schaufel "schaufel". The
lexicon keeps one row per folded form, and `dictionary_hit`'s whole-key rule picks the dictionary
term. So no catalog row could fix them: a synonym `beer → bier` would have won the form and filed
„Beeren“ under drinks.

## Fix

Migration `20261117192637_classifier_homographs.sql`, then the generated dictionary and synonym
migrations:

- `classifier_lexicon.homographs`: for a form words of different categories share, each one's
  spelling (`surface_word`: lowercase, umlauts kept, "ae" read as "ä"), canonical and category.
  Null for every other form. The form's own row stays the dictionary term's.
- `homograph_pick(homographs, name, form)`: the last word of the typed name whose key ends with the
  form; the homograph whose spelling ends that word, plus at most an inflection; longest first.
- `classifier_words(key, name)` applies it; `classifier_words(key)` is the old call without a name.
  `classify_item_detail` passes the name and lets that reading beat the dictionary's hit on the
  same form.
- Catalog: synonyms beer → bier, rolls → brötchen, sage → salbei; terms schäufele (meat), rohrnudel
  (bakery). Word list: Rohrnudeln bakery, plus the seven words and look-alikes.
- Item icons: Rohrnudeln no longer gets 🍝 (like Dampfnudeln), revision 3.

No flag: see DECISIONS „Job 282“, point 3.

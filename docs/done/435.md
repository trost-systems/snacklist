# Job 435: dismiss the store done card when the app backgrounds

**What changed.** The „… ist erledigt“ / "… is done" card (`sa-done-card`, flag `open-store-app`) is now session-only. `ListCubit` remembers which stores the user ticked in during this foreground session; only those stores may show the card, and `ShoppingListView`'s lifecycle listener (always mounted, so also while the add sheet hides the card) clears that set when the app goes `paused`, `hidden` or `detached` (not `inactive`). So the card is gone after background and resume, after „App öffnen“ on a phone, and after a cold start, however recent the last tick. The X rule, the 30/60-minute windows, eligibility, copy, goldens and analytics are unchanged. On web a hidden tab is `hidden` too (`visibilitychange`), so a store page opening in a new foreground tab dismisses the card like on a phone; a window blur alone (`inactive`) keeps it; headless Playwright never hides the page, so `journeys/store-done.mjs` fires `visibilitychange` itself. Diff does not touch `supabase/functions`.

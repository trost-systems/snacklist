# Job 279: first catalog drafting run (S4)

Draft PR, not merged: every row waits for human review (Legal N-215).

## What was built

- `catalog/drafts/2026-11-16-claude.tsv`: 519 drafted rows for the classifier catalog,
  229 dictionary terms and 290 synonyms (400 high, 117 medium, 2 low confidence). They cover German
  regional names (Semmel/Schrippe style: Weggli, Gipfeli, Knöpfle, Apfelsine, Egerling, Radi,
  Klorolle, Sackerl, Nuggi...), words the classifier files in the wrong aisle today (Plätzchen,
  Windbeutel, Schweinekamm, Wurstsalat, Spritzgebäck, Erdnussöl, Duschöl, Bügelwasser...), missing
  groceries (Schwarzwurzel, Tafelspitz, Linguine, Garam Masala, Grappa, Sorbet...) and English
  UK/US names (eggplant, courgette, crisps, nappies, cling film, scallions...).
- `catalog/REVIEW.md`: the rules the draft was made under, the format, how to review and accept,
  the unsure rows, and the words no catalog row can fix.
- `supabase/classifier/probe_drafts.sh`: loads a draft into the classifier in a rolled-back
  transaction and reports per row before/after aisle and status (`gap`, `key`, `redundant`,
  `broken`, `listed`), plus any existing word whose aisle the draft changes. `--rows accept` probes
  only the accepted rows.
- `supabase/classifier/accept_drafts.ts` (+ tests in the functions gate): moves `accept` rows into
  `dictionary.tsv` and `synonyms.tsv`, keeps rejected rows in the draft, writes the two loading
  migrations, writes nothing if the catalog would not parse.

## How to verify

- `supabase start`, then `supabase/classifier/probe_drafts.sh catalog/drafts/2026-11-16-claude.tsv`:
  472 `gap`, 39 `key` (each synonym shares its canonical's key), 8 `redundant` (canonicals other
  rows need). No dictionary, synonym, wordlist or sweep word changes aisle; 76 of the 169 compounds
  in `probe_compounds.txt` do, mostly fixes, and REVIEW.md lists the wrong ones by row.
- `cd supabase/classifier && deno test --frozen --allow-read`: 20 passed, with and without
  `catalog/drafts/` (deleting the last draft must not fail the functions gate).
- Accept path, on a scratch worktree: 5 rows accepted and 1 rejected; the script moved them and
  wrote both migrations; applied to the local DB (rolled back) Apfelsinen, Eggplant, Klorolle
  classify as produce/produce/household via synonym, Plätzchen sweets and Windbeutel bakery exact;
  the rejected Russ stays `other`. The generators' "newest migration matches the TSV" tests pass.
- `scripts/verify.sh --only gitleaks,lint,functions`: passed.

# Job 306: iOS builds on the iOS 27 SDK (2026-11-18)

App Store Connect warns on every iOS upload that builds must use the iOS 27 SDK from April 2027.
Every macOS job now runs on GitHub's `xcode-27` image and selects Xcode 27.2 (27B52), so TestFlight
builds carry the iOS 27.2 SDK. The minimum iOS stays 17.0.

## The warning text

It is not in any log. The 34 most recent Release iOS logs show fastlane's `upload_to_testflight`
succeeding ("Successfully uploaded the new binary to App Store Connect", build 1388 in run
44214167091) with no warning. fastlane does not print altool's upload warnings, and this runner
has no App Store Connect API key. The wording is in Apple's upload email or on the build's page in
App Store Connect. docs/NEEDS_PETER.md (Job 306) asks Peter to check that it is gone after the
next build.

## Why `xcode-27` and not `macos-26`

`macos-26` (images 20261102.0473 and the 20261112.0504 pre-release) has Xcode 26.0.1 to 26.6 only.
That is the brief's "stop" condition for that label. GitHub now ships one image per major Xcode:
`xcode-27` runs macOS 27, has Xcode 27.0, 27.1 (default) and 27.2, and has been generally available
since 2026-10-15. Its toolset already lists 27.3 beta, so the jobs select 27.2 by path in one place.

## What changed

- `.github/actions/xcode/action.yml`: selects `/Applications/Xcode_27.2.app` and prints the
  version and iOS SDKs, or fails with what to do. ci.yml (ios, ios-storekit), release.yml (ios),
  certificates.yml and paywall-shot.yml run on `xcode-27` and use it after checkout.
- `.github/actionlint.yaml`: declares the `xcode-27` label, which the pinned actionlint does not
  know yet.
- `scripts/gates/ios-storekit.sh` (its own CI job since job 304): the StoreKit tests stay on
  iOS 26.2. The gate downloads that runtime (8.39 GB, with one more try) in the background while
  it builds, and waits for it before it boots the simulator. The job's limit goes from 40 to 60
  minutes.
- `scripts/ios/build-for-testing.sh`: the simulator picker skips one-device runtimes such as
  `iOS-27-2-iPhone19-4`.
- `scripts/ios-paywall-shot.sh`: picks the newest runtime that supports one of its 6.7" iPhones.
  Before, it took the iPhone-Duo-only runtime and failed with "Incompatible device".
- `scripts/ios-storekit-probe.sh`: waits up to 5 minutes for the destination, as the gate does.
- Docs: CI.md "Runner images" and the merge wait (70 minutes for ios PRs, also in AGENTS.md),
  DESIGN.md, the premium feature file, DECISIONS job 306, NEEDS_PETER job 306.

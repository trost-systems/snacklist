# Job 483: the hold-flip hook survives a concurrent fetch

After every merge, merge-pr.sh starts `scripts/hold-flip-draft.sh <n>` in the background (job 476).
Its first run lost a fetch race in the shared clone:

```
error: cannot lock ref 'refs/remotes/origin/main': is at e315d18c5dfbd85171d85e0dcc24260b414cced2 but expected 0ea7ebe841d86b9ce96c23ca9a3a482d0337dfad
```

If that race hits a merge that does change gated legal text, no draft flip opens and the text
waits behind its hold with no owner (the #643 gap).

## What changed

- `scripts/hold-flip-draft.sh` fetches main, and an open flip's branch, into
  `refs/hold-flip-run/<pid>/<branch>` with `--refmap= --no-write-fetch-head`. It reads the commit
  and deletes the ref. It never writes `origin/*` or `FETCH_HEAD`, so another fetch cannot make it
  fail.
- `git_fetch` in `scripts/lib.sh` retries a fetch 3 times (1 s, then 3 s). push-pr.sh and
  merge-pr.sh use it for the fetches that must update `origin/main`.
- On a non-zero exit the script prints `hold-flip-draft: FAILED for #<n> (exit <rc>): a draft hold
  flip may be missing; rerun: scripts/hold-flip-draft.sh <n>` and appends it to
  `.git/hold-flip-draft.failed`. merge-pr.sh prints that file first. A run that gets through
  clears its own line.
- docs/CI.md: the race and the failure line. It also says that `bin/legal-go-merge` starts the
  hook too (FL7 in COMMON.md). The text that said it did not was stale.

## Proof

- `scripts/hold-flip-draft-test.sh`, case 8: with `origin/main` behind and its lock file held,
  a plain `git fetch origin main` fails (the test checks that first). The script still opens
  exactly one draft, leaves `origin/main` alone and leaves no private ref. Case 9: a fetch that
  keeps failing exits 1, prints the FAILED line and records it. A later run that gets through
  clears only that line. A last case shows `git_fetch` getting past a lock held for 0.5 s.
- Mutations: with main's `hold-flip-draft.sh`, cases 8 and 9 fail with the production error,
  `cannot lock ref 'refs/remotes/origin/main'`. Without `--refmap=`, case 8 fails the same way.
- Real clone: `origin/main` was rewound one commit, then `scripts/hold-flip-draft.sh --dry-run 643`
  ran. It checked the holds on main's real tip, e315d18c5, and left `origin/main` and
  `refs/hold-flip-run` untouched.
- `scripts/landing-test.sh`, shellcheck and `scripts/lint.sh` pass.

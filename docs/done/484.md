## Why a baseline

The listing text staged today names Siri and Alexa in all four long descriptions. Neither brand is marked live. The
copy also uses N-366's „Snacklist-Skill für Alexa“, writes "Siri: mit einem Kurzbefehl" instead of „per
Siri-Kurzbefehl“, names each brand twice and has "Siri, Alexa und die Liste selbst brauchen kein Premium." Each of
these breaks BN-1. The brief allows no copy change, and CI must stay green. So the 30 findings are listed in
`scripts/store-brands.baseline.json`, each with its reason and its whole message (the offending sentence, or the
mention count). Any other finding fails, even one with the same rule in the same file, and so does a baseline entry
the text no longer produces. Surface findings (BN-1 points 3 and 8) can never be baselined. `--publish`, run on the day a
text goes public, ignores the baseline and needs each named brand verified that day. Today it fails on all 30. No automation runs `--publish` yet: the
Play listing lane does not call it (left to the lead).

## Review 1 fixes

- The never-surface ban matches brands as substrings, so „Alexaliste“, „claudeapp“ and „Amazons“ fail as the old
  `check.mjs` did. Apple only at a word start; Gemini, Copilot and Google Assistant are banned there too.
- A description that names a brand only in a notice sentence or in the ChatGPT qualifier now counts as naming it, so a
  non-live Claude or ChatGPT can no longer get in that way.
- Point 9: a brand without a BN-1 row (Gemini, Copilot, Google Assistant and a few more) fails in a description.
- Siri's Kurzbefehl form needs „per Siri-Kurzbefehl“ and refuses compounds like „Siri-Kurzbefehl-Funktion“.
- Review 1's five probes fail; reverting the notice fix turns a test red.

## Review 2 fix

- In a description a brand is matched without a boundary after it and in its spaced or hyphenated forms
  (`Chat GPT`, `Open-AI`), so „Claudes“, „Anthropics“, „ChatGPTs“, „OpenAIs“, „Chat GPT“ and „Open AI“ name the
  brand: while it is not live they fail the live check. Review 2's six probes, prepended to the staged de-DE
  description, each fail.
- The phrasing check flags a possessive or plural (Claudes, ChatGPTs, Siris, Alexas, Siri's) as BN-1 point 4
  "never" for every brand, and a Claude or ChatGPT mention glued to letters fails the form check.
- Point 9 also lists Echo, CarPlay and GPT (a GPT model name outside „ChatGPT“).
- The staged listing gives the same findings as before: the 30 baseline entries are unchanged, and `--publish` prints
  the same 30. Three new tests (23 in all) were red before the fix and pass after it.

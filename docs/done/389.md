# Job 389: only the app's own sign-in makes personal access tokens

**Finding.** Real. An OAuth client (an MCP connection) could call `create_personal_access_token`
over PostgREST with its access token and get a token with no expiry, which kept working after the
user revoked the client's grant. `create_api_token` and `create_siri_credential` already refused
such callers.

**Fix.** Migration `20261122160000_pat_session_required.sql`: the function raises
`session_required` (42501) unless the JWT has a `session_id` and no `client_id`. Server only, no
UI or string change.

**Tests.** `supabase/tests/personal_access_tokens.test.sql`: five new cases (fail on main, pass
here). Fixtures that faked a session without `session_id` now carry one.

**Repro on the local stack (fictional user, real OAuth flow).** `repro.sh <checkout>` with the
stack's API on `$API`:

```bash
#!/usr/bin/env bash
set -euo pipefail
API=${API:-http://127.0.0.1:54321}
ANON=$(cd "$1" && supabase status -o json 2>/dev/null | jq -r .ANON_KEY)
email="oauth-pat-$RANDOM@example.test"
user=$(curl -sf "$API/auth/v1/signup" -H "apikey: $ANON" -H 'content-type: application/json' \
  -d "{\"email\":\"$email\",\"password\":\"Fictional-Pw-389\"}")
utok=$(jq -r .access_token <<<"$user")
curl -sf "$API/rest/v1/rpc/create_household" -H "apikey: $ANON" -H "authorization: Bearer $utok" \
  -H 'content-type: application/json' -d "{\"p_request_id\":\"$(cat /proc/sys/kernel/random/uuid)\",\"p_name\":\"Familie Brandt\"}" >/dev/null
redirect=http://localhost:9/callback
cid=$(curl -sf "$API/auth/v1/oauth/clients/register" -H 'content-type: application/json' \
  -d "{\"client_name\":\"Fictional MCP client\",\"redirect_uris\":[\"$redirect\"],\"grant_types\":[\"authorization_code\",\"refresh_token\"],\"response_types\":[\"code\"],\"token_endpoint_auth_method\":\"none\"}" | jq -r .client_id)
verifier=$(head -c 32 /dev/urandom | base64 | tr '+/' '-_' | tr -d '=')
challenge=$(printf %s "$verifier" | openssl dgst -sha256 -binary | base64 | tr '+/' '-_' | tr -d '=')
loc=$(curl -s -o /dev/null -w '%{redirect_url}' "$API/auth/v1/oauth/authorize?response_type=code&client_id=$cid&redirect_uri=$redirect&code_challenge=$challenge&code_challenge_method=S256&scope=openid")
aid=$(sed -n 's/.*authorization_id=\([^&]*\).*/\1/p' <<<"$loc")
H=(-H "apikey: $ANON" -H "authorization: Bearer $utok" -H 'content-type: application/json')
curl -sf "$API/auth/v1/oauth/authorizations/$aid" "${H[@]}" >/dev/null
back=$(curl -sf -X POST "$API/auth/v1/oauth/authorizations/$aid/consent" "${H[@]}" -d '{"action":"approve"}' | jq -r .redirect_url)
code=$(sed -n 's/.*[?&]code=\([^&]*\).*/\1/p' <<<"$back")
otok=$(curl -sf "$API/auth/v1/oauth/token" -d grant_type=authorization_code -d "code=$code" \
  -d "redirect_uri=$redirect" -d "client_id=$cid" -d "code_verifier=$verifier" | jq -r .access_token)
curl -s "$API/rest/v1/rpc/create_personal_access_token" -H "apikey: $ANON" \
  -H "authorization: Bearer $otok" -H 'content-type: application/json' -d '{"p_name":"minted by an OAuth client"}'
```

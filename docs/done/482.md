# Job 482: the offline dictation message names a control the sheet shows

When dictation hears a sentence but can't reach the server to split it, the app said
„Keine Verbindung. Der Text steht im Feld; prüfe ihn und tippe auf Hinzufügen.“ Neither add sheet
shows a „Hinzufügen“ button; that word is only the sheet's screen-reader label. Job 457 found it.

## What changed

- **Copy** (`app/l10n/app_de.arb`, `app_en.arb`, key `dictationSplitFailed`; the app has these two
  languages):
  - de: „Keine Verbindung. Der Text steht im Feld; prüfe ihn und tippe auf der Tastatur auf Senden.“
  - en: "No connection. The text is in the field; check it and tap Send on the keyboard."

  The add field's keyboard action is `send` (iOS shows „Senden“ / "Send", Android a send arrow), and
  dictation exists only in the phone apps, where the keyboard is up after the message.
- **Behavior** (`app/lib/list/list_screen.dart`). The new copy alone would have been false: the
  dictated text sat in the field, but the add sheet's state never learned it, so Send added nothing,
  with the sheet open or closed. Dictation that leaves text in the field now opens the sheet on it,
  as a tap on the bar does. Its rows show the text („Wie getippt“ tinted first), and Send adds it.
- **Docs.** The verify-snacklist `dictation.md` and `offline.md` recipes, the Dictation section of
  `FEATURES-FOR-WRITERS.md`, `docs/DECISIONS.md` (Job 482).

No Legal-owned file holds this text (`site/content/legal/` and the store listings don't mention it).

## How to verify

- `cd app && flutter test test/list/add_sheet_compact_test.dart --plain-name "offline dictation"`:
  four cases (German and English, sheet open or closed before the tap). Each checks the exact
  message, the open sheet, the text in the focused field, the field's `send` action, and that Send
  adds the item. All four failed with the old `list_screen.dart`.
- Drive (`verify-family-groceries`, Linux app with `FG_DICTATION='Milch und Brot'` and the add flags
  on, the stack's edge runtime stopped): the message and the open sheet in
  `docs/screenshots/482/1-offline-message.png`; Enter added „Milch und Brot“
  (`items.status = active`), `docs/screenshots/482/2-after-send.png`.

# Job 436: pin the onboarding progress bar to a fixed top position

**What changed.** The progress bar on the guided start no longer jumps to the middle on short steps. It is the same place on all seven counted steps, just under the „Schritt N von 7“ title bar.

**How it is pinned.** `OnboardingPage` takes a `pinned` widget and lays it out above the centred, shrink-wrapped list (a `Column` of the bar and `Expanded(Center(ListView))`), in the same 420-wide column with 24 px side padding (`PinnedHeader`). `OnboardingStepPage` passes `OnboardingProgress` there instead of as the list's first child. The account step, which has its own `Scaffold`, uses the same `PinnedHeader`. Page transitions, copy, steps and flags are unchanged. The bar stays excluded from semantics.

**Tests.** `app/test/onboarding/progress_bar_test.dart` pumps all seven counted steps and compares the bar's top, left and width and asserts that the steps' list heights differ (checked on the old layout: with the bar in the list the test failed on the position compare, before the pin).

left. Steps stayed at 6.

## Fixed

An invite link that the server refused for good (20 households, or a request declined in the last
24 hours) stayed pending on the device for 7 days. The router then opened that join again at every
start and sent a tap on the list back to `/join/<code>`, until the user tapped „Abbrechen“. Now
such a refusal answers the link, as an invalid code already did. Only these final answers (invalid,
20 households, declined) forget it: offline, the rate limit and a server error (a 502, 503 or
timeout, which the app reads as `other`) keep the link for a retry. Review 0 caught that the first
version forgot the link on a server error too. The fix is in `app/lib/household/join_cubit.dart` (`_refused`). Its test
failed before the fix.

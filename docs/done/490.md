## Accessibility

- Screen readers: the split row is two buttons, „Zusammenführen, 7× Bananen, …“ / „Merge, 7× Bananas, …“
  and „Abhaken, Bananen“ / „Tick off, Bananas“. Rows added in this opening end their label with „Neu“/„New“.
  The list behind the sheet is readable, but its rows' actions are blocked while the sheet is open.
- Focus: Tab from the field reaches the merge part and the tick button, each with the FH1 inset ring. The add
  field gets no ring (Peter, 27 Nov).
- 200 % text: no overflow; both actions whole and tappable (widget test and web drive).

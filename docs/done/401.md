## PostHog

The flag sync only creates flags and adds version conditions; it never switches a flag off. The
four flags stay as they are in PostHog until the lead switches them off there (NEEDS_LEAD
"Job 401: HP2 flags off"): for each of `grocery-log`, `prices-and-trip-total`, `trip-mode` and
`total-priced-only`, PostHog › Feature flags › the flag › Edit › Release conditions: delete every
condition set (is_internal, tester_groups, any person or email condition) and leave one set with
no conditions at 0 %, or switch the flag's "Enabled" toggle off; Save. Store builds and the web app
then show none of the four from their next flag read. Do not delete the flags: the sync recreates
a missing flag switched on for internal installs.

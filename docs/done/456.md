# Job 456: copy consistency audit (enabled feature set)

Audited every user-facing text on the features that are on today, in German and English: the app's
ARB files, the site (landing, guides, comparison, `llms.md`), the store listings and their notes,
the auth and tester mails, and the release changelog's rewords. The yardstick was
`FEATURES-FOR-WRITERS.md` and `releases/flags.json` (off: grocery-log, prices-and-trip-total,
trip-mode, report-content-entry, learned-order, total-priced-only, both push flags).
Legal's texts were not edited: see `456-legal-findings.md`.
